DIVYA BIRTHDAY WEBSITE — PHONE SETUP

1. Extract this ZIP.
2. Keep these files in ONE folder:
   index.html
   style.css
   script.js
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
   music.mp3

3. Replace photo1.jpg...photo4.jpg with your own photos.
   Keep the exact filenames, OR edit the names inside index.html.

4. Put your own music file in the folder and name it:
   music.mp3

5. Open index.html in Spck Editor/browser to test it.

6. Before publishing, personalize the text in index.html:
   - memories/captions
   - things you love about Divya
   - final birthday message
   - "— Yash ❤️"

7. Publish the folder using GitHub Pages.
   Your final website URL can then be converted into a QR code.

IMPORTANT:
- The music is intentionally local. Do not upload copyrighted music unless you have permission to use it.
- Phone browsers normally require a tap before audio can play, so the website has a Music button.
